# Nguyen Hoang Phuong Lam · Minimalist Portfolio

> A modern, high-craft, minimalist developer portfolio engineered with pure HTML5, CSS3, and modern modular JavaScript. Zero AI slop, zero framework bloat, 100/100 performance.

## 🚀 Features

- **Modern Minimalist Aesthetic**: Editorial typography (Inter & JetBrains Mono), crisp 1px borders, subtle glassmorphic sticky header, and balanced whitespace.
- **Bilingual Support (EN / VI)**: Real-time dual language switcher (English / Tiếng Việt) without page reloads, persisting preference in `localStorage`.
- **Theme Engine**: Seamless Dark mode (default) and Light mode with system preference fallback.
- **Deep Dive Modals**: Architectural walkthroughs for featured projects (EzSpend, E-Commerce Laptop, SneakerStore, Humify).
- **Command Palette (`Ctrl+K` / `Cmd+K`)**: Keyboard-driven navigation and quick actions.
- **1-Click Copy with Toast**: Interactive copy for `phuonglam.dev@gmail.com` with feedback toast notifications.
- **Live Vietnam Time (ICT)**: Real-time clock in Vietnam timezone (`UTC+7`).
- **Responsive & Print Optimized**: Clean rendering on mobile, tablet, desktop, and clean formatting for printing/PDF export (`Ctrl+P`).

## 💻 Local Preview

Run any lightweight HTTP server in the project directory:

```bash
# Using Python 3
python3 -m http.server 3000

# Or using Node.js npx serve
npx serve .
```

Open your browser at `http://localhost:3000`.

## 🌐 Deployment

This portfolio has zero build step and can be hosted instantly on:
- **GitHub Pages**: Push to repository and enable GitHub Pages in Settings -> Pages.
- **Vercel / Netlify / Cloudflare Pages**: Connect the repository or drag & drop the folder for instant global CDN deployment.
